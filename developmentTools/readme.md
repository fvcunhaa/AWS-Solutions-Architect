# Ferramentas de Desenvolvimento na AWS

Este diretório reúne a documentação de estudo dos principais **serviços e ferramentas de desenvolvimento da AWS**, utilizados para construção, automação, integração contínua, entrega contínua (CI/CD), testes e gerenciamento de código.

O objetivo é fornecer uma base sólida para arquiteturas modernas de desenvolvimento em nuvem, com foco em:

- DevOps
- CI/CD
- Automação
- Infraestrutura como código
- Colaboração entre equipes

---

## 🎯 Visão Geral

A AWS oferece um conjunto completo de ferramentas que suportam todo o ciclo de vida do desenvolvimento de software:

- Planejamento
- Codificação
- Build
- Testes
- Deploy
- Monitoramento
- Governança

Essas ferramentas permitem criar pipelines automatizados, reduzir erros humanos e acelerar entregas com segurança e rastreabilidade.

---

## 🧠 Serviços Abordados

### 🟢 AWS CodeCommit
Serviço de repositório Git totalmente gerenciado.

**Principais usos:**
- Controle de versão
- Repositórios privados
- Integração com pipelines CI/CD

📂 Pasta: `aws-codecommit/`

---

### 🔵 AWS CodeBuild
Serviço de build contínuo totalmente gerenciado.

**Principais usos:**
- Compilação automática
- Execução de testes
- Build de imagens Docker

📂 Pasta: `aws-codebuild/`

---

### 🟣 AWS CodeDeploy
Automação de deploy para:
- Amazon EC2
- AWS Lambda
- Amazon ECS

📂 Pasta: `aws-codedeploy/`

---

### 🟠 AWS CodePipeline
Orquestrador de pipelines CI/CD.

**Principais usos:**
- Automação de fluxo completo
- Integração entre serviços de desenvolvimento
- Deploy contínuo

📂 Pasta: `aws-codepipeline/`

---

### 🟡 AWS Cloud9
IDE baseada em navegador para desenvolvimento na AWS.

**Principais usos:**
- Desenvolvimento colaborativo
- Ambiente integrado à AWS
- Execução direta em EC2

📂 Pasta: `aws-cloud9/`

---

### 🔴 AWS X-Ray
Tracing distribuído para depuração e análise de aplicações.

📂 Pasta: `aws-xray/`

---

### 🟤 AWS CloudFormation
Infraestrutura como código (IaC).

**Principais usos:**
- Provisionamento automatizado
- Versionamento de infraestrutura
- Ambientes reproduzíveis

📂 Pasta: `aws-cloudformation/`

---

### ⚫ AWS SAM (Serverless Application Model)
Framework para desenvolvimento serverless.

📂 Pasta: `aws-sam/`

---

### ⚙️ AWS CDK (Cloud Development Kit)
Definição de infraestrutura usando linguagens de programação.

📂 Pasta: `aws-cdk/`
